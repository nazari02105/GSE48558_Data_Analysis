# GSE48558 Data Analysis: Gene Expression in AML

Analysis of microarray gene expression data from the GEO dataset [**GSE48558**](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE48558), comparing **acute myeloid leukemia (AML)** samples with **healthy blood cells**, written in **R**.

This was the course project for *Introduction to Bioinformatics* at Sharif University of Technology (Fall 2022), by Ali Nazari, Parham Bateni and Masih Najafi. The project has two phases. The assignments and our reports are included as PDFs (in Persian).

## Data

- **Dataset:** GSE48558, platform **GPL6244** (Affymetrix Human Gene 1.0 ST array), about 32,000 probes per sample.
- **Samples used:** 67 of the 170 samples in the series:
  - **18 AML** samples
  - **49 healthy** samples, from 5 cell types: granulocytes (12), B cells (11), T cells (17), monocytes (6), CD34+ stem/progenitor cells (3)
- The data is downloaded automatically by the scripts with `GEOquery::getGEO()`.

## Phase 1: Quality control, differential expression, finding the closest healthy group

Folder: `Phase1/`

The script `Phase1.r`:

1. **Downloads the data** and selects the AML and healthy samples.
2. **Finds differentially expressed genes** with `limma`, using code generated by GEO's **GEO2R** tool. It saves the results to `GSE48558.top.table.tsv` and draws QC plots: adjusted p-value histogram, Venn diagram, Q-Q plot, volcano plot, MD plot, box plot, density plot, UMAP and mean-variance trend.
3. **Checks normalization.** Values are already log2 (about 1.6 to 13.8) and the box plots line up, so no extra normalization is used. Quantile normalization was tried and made things worse.
4. **Reduces dimensions** with three methods: **PCA**, **MDS** and **t-SNE**. The report picks PCA as the best fit.
5. **Compares AML with each healthy cell type** using correlation heatmaps (`pheatmap`), saved to `comparison.pdf`.

**Result:** of the healthy groups, the **CD34+ cells** are the most similar to AML. Phase 2 uses this group.

**About `GSE48558.top.table.tsv`:** the comparison is `Healthy - AML`, so **a negative `logFC` means the gene is higher in AML** (for example, MPO and FLT3 at the top of the table). The file in the repo has all 32,321 probes. The script as written saves only the top 250. To get all probes, change `number=250` to `number=Inf` in the `topTable` call.

## Phase 2: AML vs. CD34+ cells and pathway analysis

Folder: `Phase2/`

The script `script.r`:

1. Takes the 18 AML samples and the 3 CD34+ samples.
2. Runs a **t-test for every probe** and keeps probes with **p < 0.05** (no multiple-testing correction): **7,342 probes**.
3. Splits them by mean expression: **3,680 higher in AML** and **3,662 higher in CD34+**.
4. Saves the IDs of all 7,342 significant probes to `AML_CD34_Up.txt`.

The rest of Phase 2 was done with websites, as described in the report:

- Probe IDs were converted to gene symbols with the **SynGO portal**. Some IDs could not be converted. `symbol.txt` holds the gene symbols used (400 symbols).
- The symbols were analysed in **Enrichr** (transcription factors, pathways, ontologies), and the pathways were looked up in **Reactome** and **KEGG**.
- The report also links the findings to AML papers (for example, the transcription factor E2F4) and to suggested drugs.

## How to run

### 1. Install R and packages

Install [R](https://cran.r-project.org/) and [RStudio](https://posit.co/download/rstudio-desktop/). Then run this once in R:

```r
install.packages("BiocManager")
BiocManager::install(c("GEOquery", "limma"))
install.packages(c("pheatmap", "umap", "Rtsne"))
```

The scripts start with `setRepositories()` and `install.packages(...)` lines. You can skip those lines if you install the packages this way. (`setRepositories()` asks you to pick repositories. Choose CRAN and BioC software.)

### 2. Run the scripts

You need an internet connection; the scripts download the data from GEO.

- **Phase 1:** open `Phase1/Phase1.r` in RStudio and run it **section by section** (it makes many plots). It writes `GSE48558.top.table.tsv` and `comparison.pdf` to the working folder, and later reads the table back. If your working folder is `Phase1/`, the table in the repo will be replaced with the 250-row version (see the note above).
- **Phase 2:** open `Phase2/script.r`. **Delete or change this line first**, because it points to a folder on the original author's computer:

  ```r
  setwd("D://Codes/R RStudio/Bio_Phase2")
  ```

  Then run it. It writes `AML_CD34_Up.txt` to the working folder.

## Known issues

- **`maptools` no longer exists on CRAN** (removed in October 2023). Phase 1 uses it only to label the points on the UMAP plot (`library("maptools")` and `pointLabel(...)`). Skip those two lines.
- **Phase 2 has fixed numbers in its loops:** `1:32321` (number of probes) and `1:7342` (number of significant probes found). If your numbers differ, use `length(row_names)` and `length(genes_with_p_value_less_than_0.05)` instead.
- **Names that can confuse:**
  - In Phase 1, `aml.up` (genes with `logFC > 1`) actually holds genes **higher in healthy** samples, because the comparison is `Healthy - AML`.
  - `AML_CD34_Up.txt` holds **all** significant probes, both higher and lower in AML, not only "up" genes.
